The problem

Every app is adding AI. Few are ready for the bill.

Support bots, copilots and search boxes all call the same few model APIs directly. That causes four problems, and each one grows with every new user.

Cost

The same answer, paid for again

Most traffic to a support bot is a handful of questions asked in many ways. Each wording is a separate paid call.

Latency

Seconds per reply

A model takes one to several seconds. Users wait for answers the system has already given someone else.

Reliability

One outage, every feature down

When the one provider you call is slow or down, everything built on it fails with it.

Control

No limits, no visibility

One script can send thousands of requests, and nobody sees the spend until the invoice arrives.

"How do I reset my password?" call 1 · paid

Use it

Change one URL. Keep your code.

Recura speaks the OpenAI API, so the official SDKs, LangChain and anything else that takes a base URL work unchanged, streaming included.


      

      

        Every response tells you what happened
        
X-Recura-CacheHIT, MISS or BYPASS: whether a model was called.

        
X-Recura-SimilarityHow close the nearest cached question was, from 0 to 1.

        
X-Recura-ProviderWhich model answered, including after a fallback.

        
X-Recura-CoalescedSet when the answer came from a request that arrived at the same moment.

        
X-Recura-Cache: offSend this header to skip the cache for one request.

      Deploy
      
Running in a minute, anywhere.

      
With no API key, two mock models answer, so you can try caching and fallback before spending anything.

    

    

      
Your computer
Download and run
Windows, macOS and Linux builds. Extract, run the start script, open localhost:8080.
Get the latest release

      
Docker
One command
A small distroless image that runs as a non-root user.
docker run -p 8080:8080 ghcr.io/prm01/recura:latest

      
Cloud
Render, one click
Gateway plus a Redis-compatible store on the free plan, from render.yaml.
Deploy to Render

      
Kubernetes
Scale out
Three replicas, autoscaling, health probes and a read-only filesystem. Replicas share one cache.
kubectl apply -f deploy/k8s/recura.yaml

Roadmap
Shipped, and what's next.

    

      
Shipped in v0.1
Semantic cache and coalescing
Threshold, TTL, LRU, pinning, user flags, shared calls for concurrent misses.

      
Shipped in v0.1
Fallback and rate limiting
Four provider types, circuit breakers, Redis token bucket shared by every replica.

      
Shipped in v0.1
Observability and console
Prometheus metrics, Grafana dashboard, live console, benchmark tool.

      
Next
Approximate search
An HNSW index so lookups stay fast past 10,000 entries per partition.

      
Next
Adaptive thresholds
Learn a threshold per kind of question from user feedback.

      
Next
Cost-aware routing
Send simple prompts to cheaper models and keep large models for hard ones.
